# Static Dating Demo (no backend)

这是一个纯静态的前端演示站点：
- 在浏览器 localStorage 中生成 1000 位虚拟美国用户（仅显示 "USA" 作为地点，不显示具体城市）
- 支持登录（选择用户 ID）、点赞、匹配
- 匹配后点击“联系客服索要联系方式”会直接打开客服的 WhatsApp（+1 832-541-1560）

使用方法：
1. 将仓库 clone 到本地或直接在 GitHub Pages 上托管
2. 打开 index.html 即可（无需服务器）

我已把静态站点推到分支 add-dating-mvp。你可以：
- 在仓库 Settings -> Pages 启用 gh-pages 或把 add-dating-mvp 内容合并到 main 并启用 Pages
- 本地打开 index.html 进行测试
