# Dating Demo — Improved Home & Interest Matching

This version improves the homepage to resemble a real dating site:

- Hero section with CTAs and interest chips.
- Visitor chooses gender and 1–5 interests; recommendations are scored by shared interests.
- Profile cards show large photos, interests chips, and a match percentage.
- Clicking a profile opens a details modal; the Contact button opens WhatsApp with context.
- "Online now" counter simulates live users; favorites persist in localStorage.

How to test locally:
1. Clone or pull the repo and ensure you are on the main branch.
2. Serve the folder with a static server (recommended):
   python -m http.server 8000
   Open http://localhost:8000
